# Español de México y tipografía

Interfaz en es-MX con textos comerciales originales: Crea tu cuenta, Accesorios para tu perro, Opiniones de clientes y Seguir comprando. No se copiaron anuncios ni promesas de otras marcas.

Roboto se incluye localmente en pesos 400, 500 y 700, con licencia y atribución en web/assets/fonts. Se aplica al catálogo, navegación, formularios, administración y pie de página.

Para actualizar: detén la tienda, reemplaza la carpeta web completa, ejecuta npm start y recarga con Ctrl+Shift+R. Conserva .env y data. No es necesario reinstalar dependencias.
